= trystero: serverless WebRTC rooms for {cpp}
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

trystero is a header-only port of https://github.com/dmotz/trystero[Trystero]
0.26.0's serverless WebRTC rooms for {cpp}20, one of the libraries of
https://github.com/webcpporg/webcpp[webcpp]. Peers find each other over
public Nostr relays and exchange messages directly, over WebRTC data
channels. The wire is Trystero's: a room joined from {cpp} and the same room
joined from Trystero's JavaScript are one room.
