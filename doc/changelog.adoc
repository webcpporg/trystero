== Changelog

What changed in trystero in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#trystero-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* *Breaking change:* Changed the wire to Trystero 0.27.0's: peers join after
its signed ECDSA P-256 handshake, each room has its own connections, and
signals 0.27.0 refuses are ignored.
* Added 0.27.0's users and identities: `app_config::identity`,
`create_user_identity`, `export_user_identity`, `import_user_identity`,
`room::users()`, and `room_options::max_users`, whose refusal is
`room_full`.
* *Breaking change:* Removed `app_config::self_id`, `idle_timeout`,
`room_options::handshake_timeout`, `app::max_rooms` and the errors
`too_many_rooms`, `wrong_password` and `handshake_timed_out`; `error`'s later
values moved.
* *Breaking change:* Changed each `on_*` to return a `subscription`, errors
to a `room_error`, `peers()` to a map of `peer_info`, and absent targets to
`not_connected`.
* *Breaking change:* Changed trystero's cryptography to webcpp::hash and
webcpp::crypto, libsecp256k1 included, with no sealer in the backend and no
`-sSECP256K1_ROOT`, and `backend::websocket::send` to return whether it
queued.
* *Breaking change:* Changed `native::` and `browser::` to one
`platform::backend` (link `/webcpp/trystero//platform`) over webcpp::asio,
whose page's `main` runs its `io_context`, and the clocks to `steady_now()`
and `unix_now()`.
* *Breaking change:* Changed JSON payloads and `protocol::` to
webcpp::document's documents, written as `JSON.stringify` writes them,
bounded by `room_options::max_json_document_bytes`, and `app::join` to
`+[[nodiscard]]+`.
* *Breaking change:* Changed relays to verify TLS in any verify mode, drop
binary messages, and refuse URLs a page reads otherwise and TLS contexts a
page cannot honour.
* Fixed relays hiding a genuine Nostr event or unreachable over IPv6, rooms
with colliding ids reading 8 MiB refusals, 32-bit receivers misreading 4 GiB
offers, and MSVC 14.52 builds.
* Changed the pages to the port to Trystero 0.27.0, the quick start to one
native program, and added programs showing differences beside Trystero JS's
output.
// end::unreleased[]

[#trystero-changelog-0-1-0]
=== webcpp 0.1.0

// tag::0.1.0[]
* Fixed native multiroom handoffs losing early presence frames, and
  negotiations stalled by a channel closing before room binding.
* Changed the native backend to build pinned libdatachannel sources and their
dependencies through B2, sharing source-built OpenSSL with Asio and Beast.
* Changed native builds to require `threading=multi`; the backend uses workers.
* Fixed GCC compilation of native WebSocket coroutine callbacks.
* Changed room construction to `app::join`, sharing connections between rooms.
* *Breaking change:* Removed `room_config`; construct `app` and use `join`
with `app_config` and `room_options`.
* *Breaking change:* Changed passwords to `app_config`; different passwords
require separate apps and self ids.
* Added a changelog, the page's last appendix, with each version's changes.
* Changed `config.hpp` to include `<webcpp/config.hpp>`, webcpp's
configuration, which the build adds.
* Added `WEBCPP_NO_EXCEPTIONS`, which disables trystero's exceptions with
every webcpp library's.
// end::0.1.0[]
