== Changelog

What changed in trystero in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#trystero-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* *Breaking change:* Changed `native::` and `browser::` to one
`platform::backend`, with `backend_config::memory` and `runtime`, whose
`tls_context()` is a `boost::system::result`; include
`<webcpp/trystero/platform/backend.hpp>`, link `/webcpp/trystero//platform`.
* *Breaking change:* Changed trystero's Asio to webcpp::asio; a page's `main`
runs its `io_context` under a work guard, and calls in through
`platform::page_call` of `platform/page.hpp`.
* *Breaking change:* Changed JSON payloads to `webcpp::document::document`
and `webcpp::document::pmr::document`, sent as `JSON.stringify` writes them,
for `boost::json::value` and `json_resource`; `payload` has no copy
assignment, and programs link Boost.Charconv too.
* *Breaking change:* Changed relays to verify TLS in any verify mode, drop
binary messages, and refuse URLs a page reads otherwise and TLS contexts a
page cannot honour.
* *Breaking change:* Changed a backend's clocks to `std::chrono`:
`steady_now()` and `unix_now()` replace `now_ms()` and `unix_seconds()`.
* *Breaking change:* Changed `protocol::` to take webcpp::document's values,
removing `json::parse` and `make_id`; `append_string` returns its error, and
`proposal::size` is a `std::uint64_t`.
* Fixed relays hiding a genuine Nostr event, slowing rooms with colliding ids
or making them read an 8 MiB refusal, and rooms dropping or piling up
simultaneous offers.
* Added `room_options::max_json_document_bytes` for a received JSON payload;
every JSON text is read in the room's resource within bounds, and a self id
not UTF-8 is replaced by a random one.
* Fixed unreachable IPv6 relays, signals unlike Trystero's, 32-bit receivers
misreading 4 GiB offers, pages ignoring a failing `crypto.getRandomValues` or
dropping early frames, and rooms never binding after a lost presence.
* Changed the quick start to one native program, and added programs showing
differences beside Trystero JS's output.
// end::unreleased[]

[#trystero-changelog-0-1-0]
=== webcpp 0.1.0

// tag::0.1.0[]
* Fixed native multiroom handoffs losing early presence frames, and
  negotiations stalled by a channel closing before room binding.
* Changed the native backend to build pinned libdatachannel sources and their
dependencies through B2, sharing source-built OpenSSL with Asio and Beast.
* Changed native builds to require `threading=multi`; the backend uses workers.
* Fixed GCC compilation of native WebSocket coroutine callbacks.
* Changed room construction to `app::join`, sharing connections between rooms.
* *Breaking change:* Removed `room_config`; construct `app` and use `join`
with `app_config` and `room_options`.
* *Breaking change:* Changed passwords to `app_config`; different passwords
require separate apps and self ids.
* Added a changelog, the page's last appendix, with each version's changes.
* Changed `config.hpp` to include `<webcpp/config.hpp>`, webcpp's
configuration, which the build adds.
* Added `WEBCPP_NO_EXCEPTIONS`, which disables trystero's exceptions with
every webcpp library's.
// end::0.1.0[]
