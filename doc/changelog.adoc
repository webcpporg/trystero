== Changelog

What changed in trystero in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#trystero-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* *Breaking change:* Changed `native::backend` and `browser::backend` to one
`platform::backend`; include `<webcpp/trystero/platform/backend.hpp>` and
link `/webcpp/trystero//platform` on both targets.
* *Breaking change:* Changed trystero's Asio to webcpp::asio; a page's `main`
runs its `io_context` under a work guard, and calls in through
`platform::page_call` of `platform/page.hpp`.
* *Breaking change:* Changed JSON payloads to `webcpp::document::document`, or
`pmr_document` in a resource, for `boost::json::value` and `json_resource`;
programs link Boost.Charconv too.
* *Breaking change:* Changed `payload` to lose copy assignment, and without
exceptions its copy constructor and the default one of
`webcpp::document::document`; make documents with `create()` or `parse`.
* *Breaking change:* Changed `read_signal`, `nostr::read_relay_message` and
`append_value` to take webcpp::document's values, `make_id` to `random_id`,
and `proposal::size` to `std::uint64_t`.
* *Breaking change:* Changed `protocol::json::append_string` to return its
error on text that is not UTF-8; such a local candidate is dropped, such a
self id set aside.
* *Breaking change:* Removed the backends' own connection and channel classes
for webcpp::webrtc's, and `browser::event_loop`; the backend throws nothing,
and `tls_context()` returns a `boost::system::result`.
* Changed a page's relays to the native webcpp::beast session, refusing
`http://` URLs and bounding unsent text; added `backend_config::memory` and
`backend_config::runtime`, at most 256 connections at once.
* Fixed relays at an IPv6 address being unreachable, pages ignoring a failed
`getentropy`, and 32-bit receivers misreading transfer offers of 4 GiB or more.
* Fixed rooms slowed by relays' event ids chosen to collide; channels keep
frames that arrive before a handler, 64 for 10 s.
// end::unreleased[]

[#trystero-changelog-0-1-0]
=== webcpp 0.1.0

// tag::0.1.0[]
* Fixed native multiroom handoffs losing early presence frames, and
  negotiations stalled by a channel closing before room binding.
* Changed the native backend to build pinned libdatachannel sources and their
dependencies through B2, sharing source-built OpenSSL with Asio and Beast.
* Changed native builds to require `threading=multi`; the backend uses workers.
* Fixed GCC compilation of native WebSocket coroutine callbacks.
* Changed room construction to `app::join`, sharing connections between rooms.
* *Breaking change:* Removed `room_config`; construct `app` and use `join`
with `app_config` and `room_options`.
* *Breaking change:* Changed passwords to `app_config`; different passwords
require separate apps and self ids.
* Added a changelog, the page's last appendix, with each version's changes.
* Changed `config.hpp` to include `<webcpp/config.hpp>`, webcpp's
configuration, which the build adds.
* Added `WEBCPP_NO_EXCEPTIONS`, which disables trystero's exceptions with
every webcpp library's.
// end::0.1.0[]
