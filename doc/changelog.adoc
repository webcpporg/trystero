== Changelog

What changed in trystero in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#trystero-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Fixed native multiroom handoffs losing early presence frames, and
  negotiations stalled by a channel closing before room binding.
// end::unreleased[]

[#trystero-changelog-0-1-0]
=== webcpp 0.1.0

// tag::0.1.0[]
* Changed the native backend to build pinned libdatachannel sources and their
dependencies through B2, sharing source-built OpenSSL with Asio and Beast.
* Changed native builds to require `threading=multi`; the backend uses workers.
* Fixed GCC compilation of native WebSocket coroutine callbacks.
* Changed room construction to `app::join`, sharing connections between rooms.
* *Breaking change:* Removed `room_config`; construct `app` and use `join`
with `app_config` and `room_options`.
* *Breaking change:* Changed passwords to `app_config`; different passwords
require separate apps and self ids.
* Added a changelog, the page's last appendix, with each version's changes.
* Changed `config.hpp` to include `<webcpp/config.hpp>`, webcpp's
configuration, which the build adds.
* Added `WEBCPP_NO_EXCEPTIONS`, which disables trystero's exceptions with
every webcpp library's.
// end::0.1.0[]
